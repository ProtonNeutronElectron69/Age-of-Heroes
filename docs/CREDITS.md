# Credits

## Music

All the music is instrumental and under an open licence: CC0 (public domain) or Creative Commons Attribution. The game shows this list too, under **Credits** on the main menu. `apps/client/src/musicTracks.ts` holds the same list for the game.

Every track was re-encoded as MP3 and set to the same loudness. Other changes are noted.
